2. Cara memasang website secara gratis

Saya merekomendasikan GitHub Pages.

GitHub Pages

Hosting website statis gratis dengan alamat GitHub Pages.

Buka GitHub Pages

  1. Buat akun GitHub gratis.

  2. Buat repository bernama andy-balala-games.

  3. Upload file HTML yang sudah saya buat.

  4. Ubah nama file menjadi index.html.

  5. Buka Settings → Pages.

  6. Pilih Deploy from a branch, lalu pilih main dan /root.

  7. Tunggu proses publikasi. GitHub akan memberikan alamat website.

Contoh alamat website:
